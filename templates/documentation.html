DeepTrust AI
System & Forensic Architecture

DeepTrust AI is a production forensic intelligence platform engineered to detect generative adversarial network (GAN) and diffusion-based synthetic media manipulations across multi-domain representations.

1 Platform Overview

Traditional convolutional classifiers trained purely on raw RGB pixels quickly overfit to specific generation artifacts and fail against novel generative architectures. DeepTrust AI resolves this limitation by decomposing media into four orthogonal physical and mathematical domains:

Frequency Domain (2D-FFT)

Isolates periodic high-frequency patterns and upsampling grid anomalies.

Structural Boundary (Canny Edges)

Measures contour consistency and blending seams around biological features.

Semantic Coherence (ResNet18)

Extracts 256-dimensional semantic representations of physical lighting and geometry.

Sensor Noise (Laplacian)

Verifies hardware-level optical sensor noise and acquisition uniformity.

2 Multi-Branch Image Architecture (ImageDeepfakeDetector)

Input Image (RGB, 128x128) ├── [Branch 1] 2D-FFT Magnitude (1, 128, 128) ──> SmallCNN(variant='pool2') ──> Feat 1 (64-dim) ├── [Branch 2] Canny Edge Map (1, 128, 128) ──> SmallCNN(variant='convconvpool') ──> Feat 2 (64-dim) ├── [Branch 3] ImageNet RGB (3, 128, 128) ──> ResNet18Backbone(out_dim=256) ──> Feat 3 (256-dim) └── [Branch 4] Laplacian Filter (1, 128, 128) ──> SmallCNN(variant='pool2') ──> Feat 4 (64-dim) │ Concatenate (448-dim) ▼ AttentionGate(448-dim) ◄ │ ▼ Classifier MLP: 448 → 256 → 128 → 1 │ ▼ Sigmoid Score > 0.45 → "Deepfake"

Feature Dimensions:

• Diffusion Branch: 64 dimensions

• Edge Structural Branch: 64 dimensions

• Semantic ResNet18: 256 dimensions

• Acquisition Laplacian Branch: 64 dimensions

• Concatenated Unified Vector: 448 dimensions

Decision Logic:

• Image Threshold: BEST_THRESH_IMAGE = 0.45

• Audio Threshold: BEST_THRESH_AUDIO = 0.95

• Status Formula: "Deepfake" if score > threshold else "Real"

• Confidence: round((score if Deepfake else 1 - score) * 100, 2)

4 REST API Endpoints

POST /api/predict/image

Accepts multipart file upload (file) or JSON with base64 data (image). Runs multi-branch image model, persists to PostgreSQL & Cloudinary, and returns prediction.

POST /api/predict/audio

Accepts audio files (file). Evaluates acoustic mel-spectrogram through CNN + BiLSTM attention network.

GET /api/predictions

Retrieves historical predictions stored in PostgreSQL database with optional limit and type query filters.

GET /api/health

Returns real-time health telemetry including database connectivity, loaded neural models, and storage backend provider.
